## С чего начать

1. Выполни `git fetch` и прочти `AGENTS.md` из `origin/main` (команда
   `git show origin/main:AGENTS.md`). Основная папка может стоять на старой
   ветке, её копии правил не верь. Следуй `AGENTS.md` во всём, чего нет в
   этом файле.
2. Работаешь сам, без субагентов.
3. Работаешь в своём рабочем дереве, не в основной папке:
   `git worktree add --detach ../fallout2-ce-3d-glm origin/main` (если папка
   уже есть, обнови её до `origin/main`).
4. Причины и улики по каждой задаче лежат в `runs/audit-2026-11-11.md`.

## Правила

- Одна задача, один PR. Ветка `task/NNN-slug`, сразу черновой PR с именем
  `NNN: <title>`: это замок на задачу.
- Перед тем как взять задачу, проверь, что по её номеру нет чужого
  открытого PR: `gh pr list --search "NNN:"`. Есть: бери следующую.
- `game/`, `game-vanilla/`, `build/` и любые файлы игры не коммитить.
- `git commit -a` не использовать. Добавляй файлы по именам.
- В папку Steam с Fallout 2 не писать ничего. Игру владельца
  (`game/fallout2-ce.exe`) не закрывать, `tools/dev-launch.ps1` не запускать.
  Для проверок есть только фоновая тестовая игра (`tools/dev-snapshot.ps1`).
- Перед мержем CI зелёный. Прочитай результат каждой проверки
  (`gh pr checks <номер>`) отдельным шагом; мерж в одной команде с
  проверкой запрещён. Потом `gh pr merge --squash --delete-branch`.
- Перед пушем: `py -3 tools/check_public_content.py origin/main`. В
  добавленных строках не должно быть личных путей, имён и почты.
- Длинное тире не писать нигде. Всё в репозитории на английском.
- Карточка на доске: открыл черновой PR, карточка идёт в «В работе»;
  смержил, идёт в «Готово». Оба раза запусти
  `py -3 "../!F2R board/update_board.py"`. Нет такой папки: напиши об этом
  в PR одной строкой.
- После мержа, который менял код в `ce/`, выполни Правило 1 из `AGENTS.md`:
  Release со свежего `origin/main`, `ctest`, один запуск
  `tools/dev-snapshot.ps1`, exe в `f2r-verified` со строкой в `version.txt`.
- Запреты этой ночи:
  - `ce/src/scene_renderer/` не трогать совсем: там идёт работа над
    скоростью (157).
  - `ce/src/launcher_main.cc` и `ce/src/launcher_ui.cc` не трогать: открыт
    PR #401.
  - Задачи 186, 227, 157 и 173 не брать, даже если `tools/tasks.ps1 -Next
    glm` предложит 186. Это ошибка скрипта, её чинит задача 249.
  - Задачи с генерацией картинок не брать.

пробовал, что увидел и чего не хватает; поставь `status: blocked`; закоммить,
запушь, оставь PR черновиком и бери следующую задачу из очереди. Не стой на
