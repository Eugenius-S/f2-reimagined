## Follow-up acceptance on Windows

- The two normal Temple passage directions and combat Ctrl+F12 are covered in [the dedicated evidence](../325-combat-and-exit/README.md).
- Plain F12 was tested after the native main menu, 2D world map, Inventory, Pip-Boy, Character and Sulik dialogue were visible. One synthetic SDL press/release per screen produced exactly one normal player PNG and JSON. The retained files passed PNG signature and JSON image-name checks. The fixture did not change the production capture path or test a physical key.
- Changing the resolution with Done in a hidden real Windows SDL test window resized both window and drawable to 1600x1200 at a 960x540 logical resolution. Local scene-gl stayed active. The pointer mapped to the same map tile, and the black bars rejected clicks. See [resize and pointer checks](../325-live-resize/README.md). This does not cover visible fullscreen or other monitors.
- The VSync toggle was changed through the actual Display panel with the Right key and saved with Done. The isolated settings survived restart and the OpenGL driver reported swap interval 0 before and 1 on the restarted build. No visible tearing or fullscreen claim.
- A normal click on ARBRIDGE tile 26734, one valid movement step from 26733, opened the real world map. Local 3D was off there even though the GL display backend remained active. The registered RNDWHALE encounter also completed a normal movement click on 12716 from 12715 and entered the real 2D world map. The direct RNDBRIDG startup only exposed one visible world exit; the production pathfinder found no route from the fixture spawn. That is not a result for an ordinary random encounter or the owner's save.

- The round Temple door and ordinary combat F12 now have separate native checks on tasks 317 and 318. The SharpText inventory test restored all previously occupied cursor crops on the next presented frame (319). On ARBRIDGE and RNDBRIDG, clean and marked output files were written between paired camera-matched frames; each pair matched at all 86,430 sampled world pixels and none qualified as magenta. This does not reproduce the owner-only report.

- The live dialogue close defect is covered in [a separate native comparison](../325-dialogue-close/README.md). A clean local build was necessary to establish the embedded commit: a locally cached Ninja dependency prefix in UTF-8 did not match raw CP866 MSVC output. The independent minimal stamp test reproduced this mismatch and restored dependency tracking by using the same output code page for configure and build. No mismatched local binary was staged.
