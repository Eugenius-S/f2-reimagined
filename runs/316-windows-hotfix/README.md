# Windows hotfix investigation

The investigation started from main `6f5b82bf3` with the Russian text choices from #551. The reported Windows build is `d01e850`, running Restoration Project 2.4.34. All game tests used disposable copies.

| Report | Reproduction and result |

| 1. Region capture | In Temple entrance combat, Enter and Space went through the combat loop before the mark handler. The candidate puts the active mark first and suppresses repeat through release. Instrumented SDL tests held F12 before and after confirmation and through Esc. One new press saved one set of files. Combat, player turn and 9 AP persisted after holding Enter after saving and Space through Esc. The zoom animation held while the mark was active and resumed after closing. The Russian hint and green outline were visible in ordinary and turned views. On copied `ARCAVES.SAV` e0 at hero 20467, camera 18679, zoom 1.28 and 3440x1440 at 2x, the injected logical rectangle `[1366,223,198,166]` gave the same physical rectangle `[2732,446,396,332]` in PNG and JSON. Refreshing that rectangle removed the stale arrow. The affected 70x55 crop matched the cache-disabled control pixel for pixel after the fix. The combat HUD check captured one arrow after motion and a shape change. [Inventory comparison](cursor-before-after.jpg). The stall remains unconfirmed. |

## Verification

- The Release build and all 34 CTest checks passed at the combined code commit `eb25945b8`. The Python exporter suite passed 155 tests, and the regression harness suite passed 12.
- The RP smoke test booted the copied Temple caves, Temple exterior and Arroyo on `eb25945b8` (3/3).
- The full pixel gate ran 154 spots on the first candidate in an isolated vanilla fixture. It reported 151 differences against the references and three wrong-map errors. Repeating three controls on clean main `6f5b82bf3` produced pixel-identical frames with the same reference mismatch and the same wrong map for the Den upstairs control. The full gate remains red.

The draft includes candidate fixes for region capture, cursor trails, camera travel and the held action menu. Open visual and gameplay checks still block release.
